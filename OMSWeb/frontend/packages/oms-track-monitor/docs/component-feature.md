# 기능

이 문서에서는 컴포넌트와 별도의 상호작용 없이 사용할 수 있는 기능을 소개한다.

## 카메라 이동 (Panning)

맵의 아무 위치에서 메인 마우스 버튼을 누르고 이동하고 때는 방법으로 카메라를 이동시킬 수 있다.

미니맵에서 원하는 위치를 눌러 해당 위치로 카메라를 즉시 이동시킬 수 있다.

## 카메라 확대/축소 (Zoom In/Out)

맵의 아무 위치에서 마우스 휠을 위 혹은 아래로 움직여 카메라를 확대/축소할 수 있다.

## 맵 회전(Rotate)

맵의 아무 위치에서 보조 마우스 버튼을 누르고 왼쪽 혹은 오른쪽으로 이동하고 때는 방법으로 맵을 회전시킬 수 있다.

## 카메라 초기화 (centerZoom)

맵의 아무 위치에서 마우스 휠을 클릭하여 카메라 위치를 맵의 정중앙으로 이동시킬 수 있다.

## 오브젝트 호버 이펙트 (Hover)

마우스가 위치한 오브젝트는 그림자 효과가 추가된다.

## 축척 (Scale)

컴포넌트 우측 하단에 축척 정보가 표시된다.

## 컴포넌트 자세히 (ScreenDetail)

컴포넌트 우측 하단의 `ℹ️` 버튼을 클릭하여 컴포넌트의 현재 정보를 확인할 수 있다.

- Camera
  - x y
  - viewBox
  - element
  - ratio
  - center
  - max
  - viewBox
- Scale
  - mm Per pixel
  - pixel Per mm
- Rotation
  - Rotation
- Map
  - min
  - center
  - max
  - width height
